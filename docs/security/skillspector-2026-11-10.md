### 🟡 MEDIUM: SQP\-2

**Location:** `SKILL.md:66–68`  
**Confidence:** 72%  

**Message:** The skill instructs the agent to pass a user\-supplied image path directly to an external agent provider \(\`\-\-agent\-provider claude\`\) via the \`unslopper tutor explain\` command, with no privacy disclosure to the user\. The image content \(which could include sensitive personal, medical, financial, or proprietary information visible in the screenshot\) is transmitted to a third\-party API without the user's informed consent\. Additionally, since the image path is taken from user input and passed to a shell command, there is a secondary risk of path traversal or command injection if the path is not properly sanitized before being interpolated into the CLI invocation\.

**Remediation:** 1\. Add a clear, upfront disclosure to the user before transmitting any image to an external provider, stating which provider will receive the image and what data will be sent\. 2\. Obtain explicit user consent before the image is uploaded\. 3\. Sanitize and validate the image path \(e\.g\., reject paths containing shell metacharacters, enforce absolute path resolution within an expected directory\) before passing it to the CLI to prevent command injection\. 4\. Document the data retention and privacy policies of the external provider \(\`claude\`\) within the skill description\.

- **llm\_review\_confidence:** `0.72`
- **llm\_review\_outcome:** `confirmed`

### 🟢 LOW: SQP\-2

**Location:** `SKILL.md:26–27`  
**Confidence:** 65%  

**Message:** The skill instructs the AI agent to execute subprocess CLI commands \(e\.g\., \`unslopper \-\-version\`, \`unslopper tutor teach \.\.\.\`, \`unslopper tutor quiz \.\.\.\`\) without disclosing to the user that shell commands will be run on their system\. While the \`unslopper\` tool appears to be a legitimate companion CLI for this skill, the skill provides no user consent mechanism, no warning about what is being executed, and no verification that the binary being invoked is authentic\. This creates a surface where a malicious actor who can place a fake \`unslopper\` binary in the PATH could achieve arbitrary code execution silently\.

**Remediation:** 1\. Add an explicit disclosure to users that this skill will attempt to execute the \`unslopper\` CLI on their local system before doing so\. 2\. Document the expected source/installation path of the \`unslopper\` binary \(e\.g\., via a verified package manager\)\. 3\. Consider sandboxing or capability\-flagging the shell execution so the host environment must grant permission\. 4\. Validate the binary's integrity \(e\.g\., checksum or signature\) before invoking it\.

**Evidence:**
- **llm\_review\_confidence:** `0.65`
- **llm\_review\_outcome:** `confirmed`
